# Phase 1 效能測試指南

## 🚀 快速開始

### 方法 1: 使用自動化測試工具（推薦）

```bash
# 在瀏覽器中開啟測試頁面
start tests/performance/phase1-test.html
```

**測試步驟**：

#### 測試 1: 防抖功能 🔍
1. 點選 "▶️ 執行測試" 按鈕
2. 觀察日誌輸出
3. 檢視結果：
   - ✅ **透過**：觸發 10 次，執行 1 次（減少 90%）
   - ❌ **失敗**：執行次數 > 1

#### 測試 2: 定時器最佳化 ⏱️
1. 點選 "▶️ 開始監控" 按鈕
2. **切換到其他分頁** 5-10 秒
3. 切回測試頁面
4. 點選 "⏹️ 停止監控" 按鈕
5. 檢視結果：
   - ✅ **透過**：跳過次數 > 0（頁面隱藏時正確跳過）
   - ⚠️ **未驗證**：跳過次數 = 0（需要切換分頁）

### 方法 2: 在實際應用中測試

#### 測試防抖（歷史記錄搜尋）

1. **開啟應用**
   ```bash
   start index.html
   # 或在開發伺服器中開啟
   ```

2. **開啟瀏覽器開發者工具**
   - 按 `F12` 或 `Ctrl+Shift+I`
   - 切換到 **Console** 標籤

3. **執行監控腳本**
   ```javascript
   // 在 Console 中貼上以下程式碼
   (function() {
       let renderCount = 0;
       const startTime = Date.now();

       // 嘗試找到 renderHistoryList 函式
       // 注意：這個函式可能在閉包中，需要在歷史記錄頁面執行

       console.log('%c[監控] 準備監控 renderHistoryList', 'color: blue; font-weight: bold');
       console.log('%c[提示] 請開啟歷史記錄，然後在搜尋框中快速輸入文字', 'color: green');

       // 建立全域監控函式
       window.__testRenderCount = () => {
           console.log(`渲染次數: ${renderCount}`);
           console.log(`執行時間: ${((Date.now() - startTime) / 1000).toFixed(1)}s`);
       };

       console.log('%c[提示] 輸入完成後，執行 window.__testRenderCount() 檢視結果', 'color: orange');
   })();
   ```

4. **執行測試**
   - 開啟歷史記錄面板
   - 在搜尋框中快速輸入 "test"（4 個字元）
   - 等待 500ms
   - 在 Console 執行 `window.__testRenderCount()`

5. **驗證結果**
   - ✅ **預期**：只觸發 1 次渲染
   - ❌ **最佳化前**：會觸發 4 次渲染

---

#### 測試定時器（批註輪詢）

1. **開啟應用並載入文件**
   - 上傳並處理一個文件
   - 進入歷史詳情頁（有批註功能的頁面）

2. **開啟工作管理員**
   - Windows: `Ctrl+Shift+Esc` → 切換到 "詳細資訊"
   - 或瀏覽器工作管理員: `Shift+Esc`

3. **觀察 CPU 佔用**
   - 記錄當前頁面的 CPU 佔用（例如：2%）
   - 切換到其他分頁
   - 等待 10 秒
   - 觀察 CPU 是否降至接近 0%

4. **使用 Console 監控**
   ```javascript
   // 在 Console 中執行
   (function() {
       let visibleCount = 0;
       let hiddenCount = 0;

       document.addEventListener('visibilitychange', () => {
           if (document.hidden) {
               console.log('%c[頁面隱藏] 輪詢應該跳過執行', 'color: orange');
               hiddenCount++;
           } else {
               console.log('%c[頁面可見] 輪詢恢復執行', 'color: green');
               visibleCount++;
           }

           console.log(`切換次數: 可見 ${visibleCount} 次, 隱藏 ${hiddenCount} 次`);
       });

       console.log('%c[監控啟動] 請切換分頁測試', 'color: blue; font-weight: bold');
   })();
   ```

5. **切換分頁並驗證**
   - 切換到其他標籤 → 應該看到 "頁面隱藏" 日誌
   - 切回當前標籤 → 應該看到 "頁面可見" 日誌

| 場景 | 最佳化前 | 最佳化後 | 提升 |
|------|--------|--------|------|

## 🐛 常見問題

### Q1: 測試工具顯示"函式執行 0 次"
**A**: 這是正常的！防抖的目的就是延遲執行。測試會等待 300ms 後才執行函式。

### Q2: 定時器測試顯示"未驗證"
**A**: 需要切換到其他分頁才能觸發頁面隱藏檢測。測試需要至少切換一次標籤。

### Q3: 在實際應用中看不到效果
**A**:
1. 確認你在正確的頁面（歷史記錄頁面）
2. 檢查是否有其他腳本錯誤影響
3. 開啟 Console 檢視是否有錯誤日誌

### Q4: 如何驗證最佳化真的生效了？
**A**: 使用 Chrome DevTools Performance 工具：
1. 開啟 DevTools → Performance 標籤
2. 點選錄製按鈕
3. 在搜尋框快速輸入
4. 停止錄製
5. 查詢 `renderHistoryList` 函式呼叫次數
