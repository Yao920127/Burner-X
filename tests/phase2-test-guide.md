# Phase 2 批註快取測試指南

## 📍 測試位置

### 1. 開啟歷史詳情頁

```
應用首頁 → 歷史記錄 → 點選任意一條記錄
```

應該看到類似這樣的頁面：

```
┌─────────────────────────────────────────┐
│  [僅OCR] [僅翻譯] [分塊對比] [PDF對照]    │  ← 標籤欄
├─────────────────────────────────────────┤
│                                         │
│  這是文件的內容...                       │
│  Lorem ipsum dolor sit amet...          │  ← 文字內容
│  這裡有很多段落...                       │
│                                         │
│  Each paragraph is divided into         │
│  sub-blocks for annotation...          │  ← 每個句子是一個 sub-block
│                                         │
└─────────────────────────────────────────┘
```

### 2. 右鍵點選文字

**在內容區域的任意文字上右鍵點選**

例如：
- 右鍵點選 "這是文件的內容"
- 右鍵點選 "Lorem ipsum dolor"
- 右鍵點選任何一個句子或段落

### 3. 應該看到的選單

正常情況下會彈出**批註選單**，類似：

```
┌──────────────────────┐
│ ✏️ 新增批註           │
│ 🎨 醒目提示顯示           │
│ 📋 複製文字           │
│ ...                  │
└──────────────────────┘
```

## ⏱️ 效能測試重點

### 最佳化前：
- 右鍵點選後 → **等待 200-300ms** → 選單彈出
- 大文件（1000+ 句子）延遲更明顯

### 最佳化後：
- 右鍵點選後 → **立即彈出**（< 10ms）
- 無論文件多大，延遲都很小

## 🧪 測試步驟

### 步驟 1: 檢查快取狀態

在主控台執行：
```javascript
console.log('AnnotationDOMCache:', window.AnnotationDOMCache);
console.log('已初始化?', window.AnnotationDOMCache?.initialized);
console.log('快取數量:', window.AnnotationDOMCache?.subBlocks?.length);
```

### 步驟 2: 右鍵測試

1. 在文字內容上**右鍵點選**
2. 觀察選單彈出速度
3. 觀察主控台日誌

**預期日誌**（最佳化生效）：
```
[跨子塊檢測] 開始檢測跨子塊選擇...
[跨子塊檢測] 頁面上的子塊總數: 1247
```
- ✅ 沒有延遲
- ✅ 沒有警告

**失敗標誌**（最佳化未生效）：
```
[AnnotationCache] 快取未初始化，執行動態查詢  ❌
```
- ❌ 明顯延遲
- ❌ 看到警告

### 步驟 3: 效能對比（可選）

**測量右鍵延遲**：

在主控台執行：
```javascript
// 準備計時
document.addEventListener('contextmenu', function measureTime() {
    console.time('⏱️ 右鍵選單響應時間');

    setTimeout(() => {
        console.timeEnd('⏱️ 右鍵選單響應時間');
    }, 100);

    // 只測一次
    document.removeEventListener('contextmenu', measureTime);
}, { once: true });

console.log('✅ 已準備好測量。現在右鍵點選任意文字...');
```

然後右鍵點選文字。

**預期輸出**：
```
⏱️ 右鍵選單響應時間: 2.5ms  ✅ 最佳化生效
```

**失敗輸出**：
```
⏱️ 右鍵選單響應時間: 285.3ms  ❌ 最佳化未生效
```

## 🔍 如果沒有批註選單怎麼辦？

### 情況 1: 看到瀏覽器預設的右鍵選單

可能原因：
- 頁面還沒載入完成
- 批註功能沒有啟用
- 右鍵點選的位置不對（點到了空白處）

**解決方法**：
- 等待頁面完全載入
- 確保點選的是**文字內容**，不是空白區域
- 先選中一段文字，再右鍵點選

### 情況 2: 選單沒有彈出

**檢查**：
```javascript
// 檢查批註功能是否載入
console.log('annotation_logic.js 載入?', typeof annotationContextMenuElement !== 'undefined');
```
